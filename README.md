# Tender Document Parser

Сервис для извлечения текста из документов тендеров (PDF, DOCX, XLSX).

## Использование

POST /parse - отправить файл, получить текст
GET /health - проверка работоспособности

## Развертывание на Render.com

1. Загрузите этот репозиторий на GitHub
2. Создайте новый Web Service на Render.com
3. Подключите репозиторий
4. Render автоматически развернет сервис
